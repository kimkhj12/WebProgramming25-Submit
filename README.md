홈페이지 화면은 해킹 역사 박물관 느낌을 살리기 위하여 네온그린과 짙은 회색, 검은색 등을 사용.
사이트 아이콘과 로고를 사이트 제목과 어울리는 박물관 모양의 이미지를 사용.
폰트를 다양하게 적용하기 위하여 구글 폰트를 링크해서 사용
폰트는 사이트 제목은 nanum pen script, 메뉴와 본문은 나눔고딕과 나눔 명조 등을 사용
메인 메뉴는 상단에 내비게이션 형태로 배열한 후에 메뉴를 클릭하면 서브 메뉴가 드롭다운 방식으로 나타남.
홈페이지 화면 중앙에는 메인 메뉴를 이미지화 해서 세로 슬라이드 방식을 채택해서 시각적 효과를 나타내고 해당 이미지를 클릭하면 해당 메뉴로 이동.
각각의 서브 메뉴는 카드 방식의 이미지 방식을 사용하여 해당 이미지를 클릭하면 본문 내용을 볼 수 있게 함.
메인 메뉴 중에서 해킹 연대기, 해킹 기법, 보안 기술, 미디어관 등은 서브 메뉴 본문 내용을 카드 형식으로 나타내서 그 위에 제시함.
최근 사건관은 최신 뉴스를 계속 업데이트 하기 위하여 블로그 형식을 취해서 각각의 글을 카드 형태로 나열하여 그 카드를 클릭하면 볼 수 있게 함.
모든 페이지에는 전 메뉴로 이동할 수 있는 링크를 설정함.
본문 내용은 4개의 카드를 만들고 그 위에 내용과 이미지를 넣었음.
메인 페이지에는 별도로 style.css를 작성하였고, 각각의 페이지는 해당 페이지에 맞게 style을 추가함
페이지 코딩에는 주석을 달아서 추후에 쉽게 수정할 수 있게 함.
